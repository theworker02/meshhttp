# meshhttp

Mesh encode/decode helpers for http payloads in pipelines.

**Site:** https://theworker02.github.io/meshhttp/

## Install / run

```bash
git clone https://github.com/theworker02/meshhttp.git
cd meshhttp
node src/cli.js
node --test
```
