Overview

Mesh encode/decode helpers for http payloads in pipelines. Built as a tiny zero-dependency Node toolkit with a library API and a stdin-friendly CLI.

Usage

git clone https://github.com/theworker02/meshhttp.git
cd meshhttp
node src/cli.js --help
node --test
